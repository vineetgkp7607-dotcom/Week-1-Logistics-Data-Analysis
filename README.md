# Week 1 - Logistics Data Analysis

## Project Overview

This project focuses on analyzing logistics delivery performance using Python and data analysis techniques.

The main objective is to understand delivery delays, transportation costs, delivery performance, and operational patterns from logistics data.

## Dataset

The dataset contains 25,000 delivery records and 15 columns, including:

- Delivery Partner
- Package Type
- Vehicle Type
- Delivery Mode
- Region
- Weather Condition
- Distance
- Package Weight
- Delivery Time
- Expected Delivery Time
- Delivery Status
- Delivery Rating
- Delivery Cost

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Visual Studio Code

## Analysis Performed

- Data loading and inspection
- Missing value and duplicate checking
- Data cleaning
- KPI calculation
- Delivery delay analysis
- Weather-based delay analysis
- Delivery mode analysis
- Distance vs delivery cost visualization

## Key Results

- On-Time Delivery Rate: 73.32%
- Delivery Delay Rate: 26.68%
- Average Delivery Time: 6.25 hours
- Average Transportation Cost: 864.94

Higher delay rates were observed during stormy and rainy weather conditions.

## Project Files

- `logistics_analysis.py` - Python analysis script
- `Delivery_Logistics.csv` - Dataset
- `Week 1 Strategic Planning and Data Exploration for Logistics - Vineet.docx` - Project report

## Conclusion

The project demonstrates how Python and data analysis can be used to understand logistics performance and support better delivery planning, resource allocation, and operational decision-making.
